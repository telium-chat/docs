## The two things to know

**Your home server** keeps your account and signs you into other Telium servers. **A guild** is a community with its own channels, roles and messages. You can join guilds hosted elsewhere without moving your account.

You do **not** need to run your own server to use Telium. If you do host one, a small server can handle accounts, guilds and file storage in one process. Voice calls of more than a few people may need a separate [SFU media relay](/self-hosting/sfu/).

:::caution[Telium is in alpha]
Expect changes and rough edges. Direct messages are end-to-end encrypted, but **guild text channels are not**. Before relying on Telium for anything sensitive, read [Stability](/start/stability/) and [Privacy](/security/privacy/).
:::
