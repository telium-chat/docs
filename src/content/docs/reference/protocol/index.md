These pages are for implementers. Terms such as **MUST**, **SHOULD** and **MAY** have their RFC 2119 meanings. Begin with [Signing](/reference/protocol/signing/) and run the [conformance tests](/reference/protocol/conformance/) before shipping interoperability changes.

| Page | Purpose |
| --- | --- |
| [Signing](/reference/protocol/signing/) | Canonical bytes and signature verification |
| [Federation](/reference/protocol/federation/) | Discovery and signed server requests |
| [Gateway](/reference/protocol/gateway/) | Realtime events and reconnects |
| [MLS](/reference/protocol/mls/) | Encrypted conversation frame profile |
| [Conformance](/reference/protocol/conformance/) | Fixtures and required acceptance/rejection cases |

For product behavior, start at [Architecture](/start/architecture/) or [Federation](/federation/overview/).
